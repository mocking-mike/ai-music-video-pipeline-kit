# Examples

This directory is for humans evaluating the pipeline.

Files in `examples/` are documentation and demos only. They are not part of the
active project pipeline and must never be used as:

- source footage,
- fal.ai references,
- continuity frames,
- asset-bible entries,
- storyboard frames,
- target frames,
- image-to-video inputs,
- video-to-video inputs.

The included MP4 is an output example, not a reusable production input.
